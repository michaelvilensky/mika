# 🚓 המשימות של אלון — מסמך תכנון

משחק לימוד מספרים וחיבור בסיסי לאלון (גיל 4). שונה במהותו מ-`mika-bakery` (גיל 7).

## קהל יעד
- **אלון**, בן 4
- אוהב: מכוניות 🚗, להקת מרץ 🐶, גיבורי-על 🦸‍♂️
- **אוצר מילים מוגבל** — אסור להישען על קריאה
- **טווח קשב 5-10 דקות** — מחזורים קצרים

## מטרות לימודיות
1. **זיהוי מספרים 0–10** — לזהות את הצורה של ספרה
2. **ספירה 1–10** — לספור פריטים נכון
3. **חיבור בסיסי** — סכומים עד 10

## עקרונות עיצוב (שונים מבייקרי)
| בייקרי (גיל 7) | אלון (גיל 4) |
|---|---|
| ריבוי מסכים | מסך יחיד, מינימום ניווט |
| 6 סוגי מאפים, 16 לקוחות | תמה מעורבת, דמויות מסתובבות |
| טקסט בעברית | **כל דבר נאמר בקול** — מינימום קריאה |
| 3 רמות עם בחירה ידנית | **התאמה אוטומטית** (קושי עולה אחרי 3 ברצף נכון) |
| בחירה מ-3 תשובות | tap-to-count + 2-3 כפתורים |

## מנגנון משחק (יחיד)
- **מסך אחד**: כותרת + כרטיס משימה + נקודות התקדמות
- **משימה אחת בכל פעם**: דמות + שאלה קולית + ייצוג ויזואלי + כפתורי תשובה
- **8 משימות לסשן**, ואז ברכה + הצעת הפסקה

## 3 סוגי משימות
| סוג | מטרה | דוגמה |
|---|---|---|
| **ספירה** | לספור 1-10 | "כמה מכוניות?" → מציג מכוניות → 3 כפתורי מספר |
| **זיהוי** | לזהות ספרה | "איפה המספר 5?" → 3 קופסאות עם מספרים שונים |
| **חיבור** | חיבור עד 10 | "2 + 3 = ?" → ויזואלי + 3 כפתורים |

יחסים בהתחלה: 60% ספירה, 30% זיהוי, 10% חיבור. אחרי הצלחות → איזון.

מערך אחד של דמויות שמתחלפות בכל משימה:
- **כלי רכב**: 🚗 מכוניות, 🚓 ניידות, 🚒 מכבי אש, 🚛 משאיות, 🚕 מוניות, 🚌 אוטובוסים, 🚑 אמבולנסים, 🚀 חלליות
- **גורים**: 🐶 כלבים, 🐕 גורים
- **גיבורים**: 🦸‍♂️ גיבורים, 🦸‍♀️ גיבורות
- **בונוס**: ⭐ כוכבים, 💎 יהלומים

## התאמת קושי (Adaptive)
- מעקב נפרד פר-סוג שאלה (`countMax`, `addMax`, `recogMax`)
- **+1 קושי אחרי 3 נכונות ברצף** באותו סוג
- **−1 קושי אחרי 2 טעויות ברצף** באותו סוג
- ערכי התחלה: count=3, recog=5, add=3
- ערכי תקרה: count=10, recog=10, add=10 (סכום)

## דיבור (TTS)
- כל שאלה נאמרת בקול (`speechSynthesis`, `he-IL`)
- בעת הקלקה על פריט לספירה: אומר את המספר הבא ("אחת!", "שתיים!"...)
- ברכת הצלחה: "כל הכבוד אלון!", "מצוין!", "אלוף!"
- אם אין קול עברית → השתקה (לא לדבר באנגלית!)

## שמירה (V2)
- **לוקאלית**: כל מצב המשחק (מדליות, רמות קושי, סאונד) ב-`localStorage`
- **ענן**: סנכרון אוטומטי ל-Netlify Blobs דרך `/api/profile/save` ו-`/api/profile/load`
  - בכל `saveSave()` נדחפת שמירה דחויה לענן (debounced 2s)
  - בעת טעינת המשחק - pull אסינכרוני מהענן, אם cloud `updatedAt` חדש מהלוקאלי → עדכון אוטומטי
  - בלי profile picker (אלון יחיד) — קוד סנכרון אחד שנוצר אוטומטית בכניסה הראשונה
- **כפתור 🔑 בכותרת** מציג את הקוד הנוכחי + אופציה להחליף לקוד אחר (להעביר משחק ממכשיר אחר)
- אם אין רשת/הענן לא עונה → נכשל בשקט. המשחק עובד 100% offline.

## ארכיטקטורת הענן
- **פונקציות**: `alon-missions/netlify/functions/profile-{save,load}.mjs` — עותק זהה של אלה של הבייקרי (כי Netlify Blobs Stores הם per-site)
- **חבילה**: `alon-missions/package.json` מצהיר `@netlify/blobs`
- **תצורה**: `alon-missions/netlify.toml` עם `functions = "netlify/functions"`
